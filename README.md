# GENOMICS

An educational genomics website built with HTML, CSS and JavaScript.

## Run locally
Open `index.html` in a modern browser.

## Deploy
This is a static website. It can be deployed using GitHub Pages or Render Static Sites.

## Scientific note
The Virtual Lab contains fictional teaching sequences and simplified simulations. It does not sequence or analyse personal DNA.
