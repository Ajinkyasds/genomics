02 — MOLECULAR FOUNDATIONS

Four letters.
One remarkable code.

DNA is built from four kinds of nucleotide. Their nitrogenous bases are adenine (A), thymine (T), guanine (G) and cytosine (C).

Apairs withT
Gpairs withC

RNA uses uracil (U) instead of thymine (T). In RNA, A commonly pairs with U.

04 — READING THE CODE

How do we read a genome?

DNA sequencing determines the order of nucleotide bases in a DNA molecule.

CLASSICAL METHOD

Sanger sequencing

Uses chain-terminating ddNTPs to generate DNA fragments of different lengths, which can be used to infer a sequence.

A T G C A G T C
HIGH-THROUGHPUT

Next-generation sequencing

Sequences many DNA fragments in parallel, producing large collections of reads.

SEQUENCING STRATEGY

Shotgun sequencing

Breaks DNA into smaller fragments, sequences them, then uses computational methods to reconstruct longer sequences.
